Aplicația este un sistem de gestiune pentru un lanț de 3 policlinici, fiecare cu denumire, adresă, program și servicii medicale specifice. Baza de date este relațională, implementată în MySQL, iar aplicația este construită în Java, cu interfață grafică realizată în JavaFX.

Autentificarea se face cu e-mail și CNP, iar utilizatorii sunt împărțiți în 5 roluri (Medic, Asistent, Recepționer, HR, Financiar), fiecare având acces la funcționalități specifice. Drepturile sunt grupate în 3 niveluri: angajat, admin, super-admin.

Funcționalități cheie:

Gestionare utilizatori și angajați (salarii, ore lucrate).

Programări și servicii medicale personalizate.

Vizualizare liste pacienți, rapoarte medicale și tranzacții financiare.

UI intuitiv, cu tabele dinamice, validări și interacțiune directă cu baza de date.

Aplicația oferă un mod eficient de administrare digitală a unei rețele medicale moderne.
